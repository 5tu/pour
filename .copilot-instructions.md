# Copilot / Automated Agent Instructions

**Do not modify README.md**

- Never update, overwrite, or rewrite `README.md` automatically.
- If a change request involves the README, ask the repository owner for explicit confirmation before making edits.
- Prefer adding new documentation files (e.g., files under `docs/` or `docs/<topic>.md`) or proposing README edits as a PR, rather than editing README directly.

If you are an automated assistant (Copilot, script, CI job), stop and confirm with the user before touching the README.
